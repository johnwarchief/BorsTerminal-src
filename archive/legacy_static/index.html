🛜 راهنمای اتصال اینترنت و چرخش IP

🎯 چرخش IP با گوشی (ADB) چیست؟
وقتی سایتهای بورس درخواستهای پشتسرهم را مسدود کنند (۴۲۹)، بهجای انتظار طولانی، برنامه خودکار اینترنت گوشی را ~۲ دقیقه قطع/وصل میکند تا یک IP تازه از اپراتور بگیرد و اسکن همانجا ادامه یابد. سریعترین گزینه؛ مخصوص کسی که اینترنت سیستم را از گوشی میگیرد.
🔌 راهاندازی گوشی (فقط یک بار):
  1. گوشی را با کابل USB به این سیستم وصل کن.
  2. در تنظیمات گوشی: Developer Options → USB Debugging را روشن کن (اگر گزینه نیست، ۷ بار روی «شماره ساخت» ضربه بزن).
    3. ⭐ برچسب‌ها
  3. USB Tethering را فعال کن — اینترنت سیستم از گوشی تأمین میشود.
  4. در پنجره Allow گوشی تأیید کن و دوباره روی ❓ بزن تا وضعیت تایید شود.
اگر از اینترنت گوشی استفاده نمیکنی، toggle زیر را خاموش کن — اسکن به حالت صبر نرمال برمیگردد (مسیر ده سیتا‌ی رسمی + گزینههای پوکسی موجود).
