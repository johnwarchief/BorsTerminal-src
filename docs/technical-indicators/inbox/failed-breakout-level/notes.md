# MSnR Double Breakout Failed Level — بررسی اولیه

- **نوع:** Pine Script v6 Indicator
- **وضعیت:** نامزد با اولویت متوسط؛ از حذف قبلی بازگردانده شد.
- **منطق قابل مشاهده:** سطح از توالی کندل‌های سبز/قرمز ساخته می‌شود؛ شکست و بازگشت ناموفق سطح را در دو نوع A/V دنبال می‌کند. تنظیماتی مثل scan length (پیش‌فرض ۲۰۰ کندل)، حداکثر سطوح و نمایش نوع شکست دارد.
- **نکتهٔ مثبت:** منطق رویدادها در بخش‌های مهم با `barstate.isconfirmed` کنترل شده است.
- **ارزش احتمالی:** تشخیص Failed Breakout / Failed Level می‌تواند برای تحلیل شکست کاذب، مقاومت/حمایت flip شده و ارزیابی الگوها مفید باشد.
- **محدودیت:** سطحی که از جفت کندل تعریف می‌شود لزوماً با سطح ساختاریِ swing/pivot یکسان نیست. باید با سطح‌های تأییدشدهٔ خودمان مقایسه شود؛ هم‌پوشانی احتمالی با CHoCH یا ساختار FTS دلیل رد خودکار نیست.
- **گام بعدی:** تصویر چارت با سطوح A/V و تنظیمات، سپس آزمون کندل‌به‌کندل و سنجش ارزش افزوده روی بازار ایران.
- **FTS:** خارج از رأی رسمی FTS باقی می‌ماند.
