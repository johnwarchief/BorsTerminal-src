## دربارهٔ خواندن EX4 / EX5

می‌توان container/header نسخه و اندازه را خواند و رشته‌های ASCII/metadata را جست‌وجو کرد. در بررسی فعلی:
- marker فایل‌های EX4/EX5 قابل شناسایی بود.
- در `Fibo.ex4` چند رشتهٔ معنی‌دار شامل نام سازنده و دو نام پارامتر پیدا شد.
- در اغلب باینری‌های دیگر، رشته‌های قابل‌مشاهده بیشتر نویز باینری بودند؛ استخراج سورس یا فرمول از این روش ممکن نیست.
- این نتیجه به معنی بی‌ارزش بودن فایل نیست. مرحلهٔ بعدی، مشاهدهٔ خروجی واقعی در ترمینال سازگار و مقایسه با تنظیمات است؛ در صورت وجود، سورس MQ4/MQ5 یا لینک اصلی را هم اضافه کنید.

## شواهدی که برای هر باینری لازم است

1. اسکرین‌شات چارت بعد از اضافه‌شدن فایل به MT4 یا MT5؛
2. اسکرین‌شات کامل Inputs/Settings؛
3. نام نماد، تایم‌فریم، تاریخ نمونه و منبع داده؛
4. اگر ممکن است، یک نمونهٔ سیگنال و یک نمونهٔ بدون سیگنال؛
5. منبع دانلود/نام سازنده و شرایط استفاده.

فایل ناشناس را روی حساب واقعی اجرا نکنید. اگر ترمینال برای نمایش لازم است، از پروفایل آزمایشی و بدون اتصال حساب واقعی استفاده شود. نوع واقعی (Indicator یا Expert Advisor) باید با رفتار ترمینال و متادیتای معتبر تعیین شود، نه فقط نام فایل.
