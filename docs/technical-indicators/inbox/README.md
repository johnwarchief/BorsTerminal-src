# Technical Indicator Inbox — پالایش‌شده و قابل توسعه

## فایل‌های EX4 / EX5 را چطور بررسی می‌کنیم؟

این فایل‌ها باینری کامپایل‌شدهٔ MetaTrader هستند و با سورس Pine یا MQL قابل‌خواندن یکسان نیستند. با ابزارهای متنی می‌توان بعضی مشخصات اولیه مثل magic/header، رشته‌های قابل‌مشاهده و metadata را بیرون کشید؛ اما فرمول داخلی و منطق سیگنال از این رشته‌ها به‌تنهایی به‌دست نمی‌آید.

برای همین فایل‌ها:
- فایل اصلی بدون تغییر نگه داشته می‌شود.
- پسوند EX4/EX5 به‌تنهایی برای تشخیص Indicator در برابر EA کافی نیست.
- در صورت امکان، همان نسخه در MetaTrader 4 یا 5 و روی محیط آزمایشی بدون اتصال به حساب واقعی نمایش داده شود.
- تصویر چارت، تصویر تنظیمات و مشخصات نماد/تایم‌فریم برای بررسی خروجی لازم است.
- اگر سورس MQ4/MQ5 یا صفحهٔ اصلی سازنده موجود است، از خود فایل باینری ارزشمندتر است.

**نمونهٔ بررسی باینری انجام‌شده:** در `Fibo.ex4` رشته‌های قابل‌خواندن `Don Perry`، `lookback`، `lastbar` و `Fibo` استخراج شدند. این‌ها فقط metadata و نام پارامترند و فرمول Fibo یا سیگنال‌های آن را اثبات نمی‌کنند. در باینری‌های دیگر رشته‌های معنادار بسیار محدودی دیده شد؛ آن‌ها حذف نشده‌اند و برای بررسی رفتاری نگه داشته شده‌اند.

## راهنمای ارسال عکس

برای هر موردی که خروجی آن روی نمودار برایت مهم است، این دو تصویر را قرار بده:
1. **Chart screenshot:** نمودار با خود اندیکاتور و سیگنال/ناحیه‌ای که مهم می‌دانی.
2. **Settings screenshot:** تمام تنظیمات همان نسخه.

کنار تصویر بنویس: نماد، بازار، تایم‌فریم، تاریخ/ساعت نمونه، منبع کندل و اینکه نمودار خام است یا تعدیل‌شده. برای فایل‌های MT4 از MT4 و برای MT5 از MT5 عکس بگیر. برای بررسی اولیهٔ سورس Pine، عکس الزامی نیست؛ برای بررسی بصری باینری‌ها بسیار مفید و عملاً لازم است.

## دسته‌بندی و تصمیم‌ها

- **Priority / Research:** ایده و منطق ارزش بررسی جدی دارد؛ هنوز پذیرش تولیدی نیست.
- **Exploratory:** ممکن است ماژول یا بخش ارزشمند داشته باشد؛ ابتدا باید از بستهٔ ترکیبی جدا و ارزیابی شود.
- **Binary pending:** نوع/منطق داخلی از باینری به‌تنهایی مشخص نیست؛ حذف یا رد نمی‌شود.
- **Not an indicator:** سورس به‌وضوح EA، Strategy یا ابزار Replay است؛ از Inbox اندیکاتورها خارج می‌شود، نه از ارزش پژوهشی کل پروژه.

## مرزبندی با FTS

هیچ‌کدام از این موارد مجاز نیستند قواعد رسمی FTS، veto هفتگی، Jet، CHoCH، Fibonacci، Hourglass یا قواعد خروج را تغییر دهند. اگر پذیرفته شوند، ابتدا به‌عنوان لایهٔ مستقل Indicator / Pattern Research پیاده‌سازی و آزمایش می‌شوند. «هم‌پوشانی با FTS» به‌تنهایی دلیل حذف نیست؛ مقایسهٔ پیاده‌سازی‌ها می‌تواند ارزشمند باشد.
