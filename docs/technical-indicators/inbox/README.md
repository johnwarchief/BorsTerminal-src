# Indicator Inbox

فایل‌ها و منابع تازه را اینجا قرار دهید. برای مرتب‌ماندن پوشه، برای هر اندیکاتور یک زیرپوشه بسازید.

نمونه:

```text
inbox/
  supertrend-variant/
    source-link.txt
    notes.md
    indicator.pine
    reference.png
```

پیشنهاد می‌شود در هر پوشه، در صورت دسترسی این موارد ثبت شود:

- لینک و نام منبع/سازنده؛
- فایل اصلی یا کد، بدون تغییر؛
- اسکرین‌شات واقعی و تنظیمات مورد استفاده؛
- بازار، نماد، تایم‌فریم و حالت تعدیل نمودار؛
- توضیح مختصر از اینکه چرا اندیکاتور جالب است یا چه مشکلی را حل می‌کند.

اگر همهٔ این اطلاعات را ندارید اشکالی ندارد؛ اطلاعات موجود را بگذارید و چیزی را حدس نزنید. ایجنت باید قبل از ادغام، منبع، رفتار محاسباتی، repainting، look-ahead، مجوز استفاده و سازگاری فنی را بررسی کند.


## تشخیص نوع فایل و ایمنی

این پوشه می‌تواند فایل‌های متفاوتی داشته باشد؛ هر فایل `.mq4` یا `.mq5` را خودبه‌خود «اندیکاتور» فرض نکنید. این پسوندها می‌توانند کد Indicator، Expert Advisor (ربات معاملاتی)، Script یا Library باشند؛ ایجنت باید نوع واقعی را از ساختار کد تشخیص دهد.

فایل‌های کامپایل‌شدهٔ `.ex4` و `.ex5` معمولاً منبع قابل‌بررسی کامل نیستند. آن‌ها را مستقیماً اجرا نکنید، به موتور تکنیکال منتقل نکنید و ادعا نکنید فرمول داخلی‌شان قابل‌تأیید شده است. برای بررسی قابل‌اعتماد، سورس اصلی، شرح سازنده، تنظیمات و نمونهٔ خروجی لازم است.

اگر مورد ارسالی قابلیت ثبت/لغو سفارش یا مدیریت معامله دارد، آن را **ربات/اکسپرت** دسته‌بندی کنید، نه اندیکاتور. هیچ فایل ناشناس را به حساب واقعی متصل نکنید. هر مورد پیش از ادغام باید از نظر نوع فایل، منبع، مجوز استفاده، منطق و repainting بررسی شود.
