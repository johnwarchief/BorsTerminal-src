# 3rd Wave BB TrendLines — بررسی اولیه

- **نوع:** Pine Script v5 Indicator
- **وضعیت:** اکتشافی؛ حذف نمی‌شود تا وابستگی و نمونهٔ بصری بررسی شود.
- **قابلیت‌های قابل مشاهده:** تشخیص Third Wave با ZigZag، ناحیهٔ retracement پیش‌فرض 0.382–0.786، اهداف موج، Bollinger Bands و RSI؛ علاوه بر trendlineهای پیوتی.
- **وابستگی:** `LonesomeTheBlue/CreateAndShowZigzag/1`؛ سورس/نسخه و مجوز کتابخانه باید بررسی شود.
- **ریسک اصلی:** الگوهای Elliott و ZigZag نسبت به انتخاب پیوت و hindsight حساس‌اند. تأخیر تأیید و هرگونه بازنویسی پیوت باید صریح اندازه‌گیری شود.
- **گام بعدی:** از قابلیت‌های مستقل (trendline، BB، RSI، wave pattern) نمونهٔ تصویری بگیر و جداگانه ارزیابی کن؛ کل اسکریپت ترکیبی را یک واحد غیرقابل‌تفکیک تلقی نکن.
- **FTS:** یک خانوادهٔ الگوی پژوهشی مستقل است و نباید قواعد FTS را بازتعریف کند.
