## ت. موتور، API و هر دو موتورِ چارت (مرحلۀ ۳ تا ۵)

**مسیرِ واقعیِ سریِ عملکردی (یک منبع، بی‌محاسبۀِ موازی):**

```
market.db (price_adjust/share_change) + CSVِ گسستِ قیمتِ پایه
  → api/chart.py::_adjust_events_from_rows      (سیگنالِ گسست + VOL=0 + نگهبانِ لنگر)
  → _collapse_zero_volume_runs → _sharpen_events_with_ledger (دفتر فقط عدد را تیز می‌کند، گامِ تازه اضافه نمی‌کند)
  → _engine_events → adjustment_engine.chain_factors (پیمایشِ معکوسِ O(n+m)، لنگر=۱ درِ تازه‌ترینِ روز)
  → payload: candles + factors[{time,factor}] + adjustEvents + adjustRejected + adjustCapability{coverage, functional_blockers}
  → frontend: applyAdjustmentToCandles()  ← تنها نقطۀِ ضربِ ضریب درِ کلِ مرورگر
     ├─ KLineCharts (chart.setDataLoader → renderCandles)
     └─ FFC (TechnicalPage → engineBars → adapter.setBars)
```

- **قبل از این دور:** مرورگر از `adjustEvents` زنجیرۀِ **دوم** می‌ساخت (فیلترِ ۰٫۰۲–۵۰ رویدادها را کم می‌کرد
  و با حلقۀِ سرور واگرا می‌شد)؛ `functional_available` سخت‌کد بود. **بعد:** یک محاسبه، ضرایبِ سرور، و
  `functional_available` **محاسبه‌شده** با شمارشِ مانع‌ها.
- **double-apply:** درِ مرورگر واقعی سنجیده شد — آخرین میله در «خام» و «عملکردی» یک عدد است
  (`none=7060 comb=7060`) و نسبتِ دیدنیِ یک میلۀِ قدیمی **دقیقاً** ضریبِ سرور:
  میله `2026-07-20` خام=۴۶۰ → عملکردی=۴۰۶۰، `ratio=0.88260870` = `factor=0.8826087`
  (`_audit/PHASE5G-UI.json`).
- **انتخابِ درستِ سری درِ هر دو موتور، از خودِ رندرر** (نه حدسِ پیکسل): `chart.getDataList()` برای
  KLineCharts و `adapter.bars` برای FFC، میله‌به‌میله با مرجعِ سرور:
  `تطبیق=3427 بی‌مرجع=0 اختلاف=0` برایِ هر سه حالتِ خام/عملکردی/بازدهی، و همان سنجش برایِ نمادِ دوم
  (`فولاد`، ۴۲۴۵ میله) و برایِ FFC (`اختلافِ سریِ عملکردی با خام = ۳۳۷۱ میله`).
- **حالت‌هایِ غیرفعال** (افزایش سرمایه / سود نقدی): کلیک نامِ حالت و سری را عوض نمی‌کند (برچسبِ باز‌گشتی
  دقیق مقایسه می‌شود) — بی‌دکمۀِ mock.
- **نگهبانِ ضدِ بازگشت:** `dev/test_adjustment_phasea.py` (۵۷ بررسی) + `technical-settings-effectiveness.spec.tsx`
  (۱۱ بررسیِ jsdom: قفلِ درگِ محورها، حاشیۀِ محور، شمعِ خاکستری، واترمارک، کاربردِ ضرایبِ سرور، اعلامِ مانع)
  + `technical-weekly-wiring.spec.ts` / `technical-corp-events.spec.ts` (سیمِ تک‌منبعی).
- **تغییرِ حالت/نماد/بازه/موتور پس از اتصال:** هفتگی↔روزانه (۷۷۵↔۳۴۲۷ میله، برگشت = همان سری)،
  سوییچِ نماد، سوییچِ موتور و «بازگشت به KLineCharts»، و resize درِ ۳۹۰×۸۴۴ — همگی درِ Edge سبز،
  بی‌هیچ خطای Console.
