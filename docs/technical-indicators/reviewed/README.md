# Reviewed Indicators

مواردی در این مسیر قرار بگیرند که بررسی اولیهٔ آن‌ها انجام شده و نتیجه‌ای مستند دارند؛ چه پذیرفته شده باشند، چه رد شده یا برای بررسی بیشتر نیازمند اطلاعات باشند.

برای هر مورد، نتیجه باید شامل منبع، منطق، پارامترها، وضعیت repainting/look-ahead، مجوز استفاده، شواهد مقایسه و تصمیم بعدی باشد. قرارگرفتن در این پوشه به معنی ادغام در محصول نیست.
