# Implemented Indicators

اینجا مستندات اندیکاتورهایی قرار بگیرند که واقعاً در BorsTerminal پیاده‌سازی و با تست‌های لازم تأیید شده‌اند.

برای هر مورد مسیر کد، پارامترهای پشتیبانی‌شده، منبع مرجع، تست‌ها، محدودیت‌های شناخته‌شده و کامیت ادغام را ثبت کنید. فایل‌های این پوشه به‌تنهایی جایگزین کد اجرایی برنامه نیستند.
