# PLAN-android — نسخهٔ اندروید BorsTerminal (شروع دور تازه)

> وضعیت: برنچ `feat/android` از `main` ساخته شد (۱۴۰۵-۰۷-۰۷ / 2026-09-29). مبنا: بررسی کامل پروژه در همین تاریخ.
> فرض این دور: مسیر «Termux نسل جدید» — اجرای همان بک‌اند FastAPI و SPA بیلدشدهٔ فعلی روی گوشی. اگر مسیر دیگری (پوستهٔ WebView/PWA یا بومی) انتخاب شود، این پلن به‌روزرسانی می‌شود.

## چرا Termux به‌عنوان گام اول
- بیشترین بازاستفاده از کد فعلی (بک‌اند + `frontend/dist`)، کم‌ترین دوباره‌کاری.
- یک نمونهٔ قدیمی این مسیر وجود داشت (نسل قبل اپ) اما به UI قدیمی سرو می‌داد و ادامه پیدا نکرد؛ این دور روی اپ فعلی (v1.0.x) ساخته می‌شود.

## گام‌ها
1. اسکریپت‌های `android/` نسل جدید: نصب (python/pandas/fastapi/uvicorn)، اجرا بدون `--reload` و بایند به `127.0.0.1`، سرو `frontend/dist`.
2. سیاست داده: انتقال `market.db.lzma` + استخراج اولین اجرا؛ جدایی `user.db`.
3. محدودیت‌ها: روی گوشی xray/adb نیست → مسیر جایگزین برای WAF کدال (پروکسی محلی/سرور اختیاری) + مستند صریح «چه کار نمی‌کند».
4. سخت‌سازی: توقف امن، لاگ ساعت‌دار، بدون باز بودن سرویس روی کل شبکه.
5. توزیع: راهنمای نصب یک‌مرحله‌ای؛ گام بعدی محصولی: پوستهٔ WebView/PWA (APK).

## قیدهای قطعی
- `numpy==2.0.2` (پین عمدی برای CPUهای قدیمی — «مدرن‌سازی» نشود)، pandas طبق `requirements.txt`.
- قرارداد دادهٔ سه‌گانه و beside-exe حفظ شود؛ `user.db` دست‌نخورده.
- مسیر انتشار/امضای ویندوز دست‌نخورده بماند؛ نسخهٔ اندروید مسیر مستقل دارد.
