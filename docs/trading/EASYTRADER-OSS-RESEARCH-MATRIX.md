## قواعد این بررسی (و چیزی که این سند هرگز ادعا نمی‌کند)

- فقط **خواندنِ ایستای کد**. هیچ کدی اجرا نشد، هیچ وابستگی‌ای نصب نشد، و **هیچ درخواستی به
  کارگزاری فرستاده نشد** — نه سفارش، نه «ping» روی درِ سفارش.
- هیچ token / cookie / رمز / مقدار Authorization در این سند، در لاگ یا در Git نیست؛
  فقط *مکانیزم* نگهداری توصیف شده است.
- **هر endpoint در این سند یک فرضیۀ تحقیق است.** وجود یک مسیر درِ یک مخزن عمومی مدرکِ
  پشتیبانی رسمی کارگزاری نیست (تأیید آن فقط درِ نشستِ مجاز و نسخۀ جاری ممکن است — بند ۲).
- شمارۀ README هیچ‌جا benchmark تأییدشده تلقی نشده است.
- چیزی که از کد قابل اثبات نبود صریحاً `UNVERIFIED` خورده است.
