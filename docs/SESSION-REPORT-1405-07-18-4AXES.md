   تمام‌بازارِ مستقل‌اند. **داورِ canonical (`/api/funnel`) زنجیره‌ای است و گارد دارد**؛
   این مسیرها صفحه‌هایِ دیگری را تغذیه می‌کنند و دگرگون‌کردنشان رأیِ مالک می‌خواهد

2. **preset «ساعت شنی» زنجیرۀ تابلویش خالی است** (`funnel_registry.py`) — یعنی گیتِ
   تکنیکال رویِ کلِّ جامعۀ غربال می‌دود و تابلوخوانی دور زده می‌شود. درِ رجیستری

3. **کنترل‌هایِ بی‌مصرفِ نوارِ تابلو:** `TapeFilterSettingsModal` (با چهار presetِ

   `exitAccum` درِ `applyFilters` مصرف می‌شوند ولی هیچ کنترلی آن‌ها را روشن نمی‌کند؛
