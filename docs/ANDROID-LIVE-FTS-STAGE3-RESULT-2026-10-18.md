# نتیجهٔ مرحلهٔ ۳ — واکشی و تطبیق واقعی Codal

**تاریخ اجرا:** 2026-10-18
**دامنه:** یک گزارش سالانهٔ حسابرسی‌شده برای خساپا؛ بدون VPS، بدون دادهٔ ساختگی، و بدون تغییر فرمول FTS.

## اجرای زنده از میزبان توسعه

مسیر `syncLatestAnnualFinancialStatement` با `fetch` واقعی و یک storage capture اجرا شد. جست‌وجوی Category 1 و هر سه صفحهٔ گزارش HTTP 200 برگرداندند: صفحهٔ اصلی 83,043 بایت، صورت سودوزیان مستقل با `sheetId=1` برابر 123,691 بایت، و وضعیت مالی مستقل با `sheetId=0` برابر 193,778 بایت. درخواست‌ها سریالی و با فاصلهٔ throttle کد انجام شدند.

گزارش انتخاب‌شده TracingNo `1561668` است؛ عنوان رسمی آن صورت‌های مالی تلفیقی سال مالی منتهی به `1404/12/29` (حسابرسی‌شده) است. صفحهٔ گزارش هم شیت تلفیقی و هم شیت مستقل دارد؛ انتخاب‌گر، شیت مستقل را برای ورودی FTS انتخاب کرد. نتیجهٔ parser: `PARSED`، دورهٔ ۱۲ماهه، حسابرسی‌شده، `consolidated=false`.

## نوشتن و بازخوانی پایگاه داده

رکورد و نتیجهٔ همین واکشی زنده با `createCodalStore` و `sql.js` در SQLite schema v2 نوشته شد. سپس یک نمونهٔ تازه از store روی همان bytes پایگاه داده باز شد و فیلدهای کلیدی همان مقادیر را برگرداند: درآمد `868072075`، EPS `-154`، دارایی‌ها `2955404908`، دوره `1404/12/29` و وضعیت `PARSED`. رکورد خام، عنوان گزارش و source URL نیز حفظ شدند.

این آزمون لایهٔ SQLite و round-trip را ثابت می‌کند؛ storage آن adapter حافظه‌ای بود، نه Cache API واقعی WebView. اجرای زنده از مسیر CapacitorHttp روی گوشی و ماندگاری پس از بستن و بازکردن اپ هنوز تأیید نشده است.

## محدودیت‌های باقی‌مانده

- `adb devices -l` دستگاهی نشان نداد؛ Android SDK، emulator و JDK نیز روی این ماشین حاضر نبودند. APK ساخته یا نصب نشد.
- دسترسی از شبکهٔ گوشی به Codal، رفتار CapacitorHttp، و ماندگاری Cache API در WebView راستی‌آزمایی نشده است.
- موتور بنیادی FTS و قیف استراتژی Android هنوز پیاده/تطبیق نشده‌اند؛ این نتیجه فقط قرارداد واکشی و استخراج یک گزارش را می‌سنجد.
- آزمون یک نماد و یک گزارش، پایداری نرخ درخواست یا پوشش کل Universe را اثبات نمی‌کند.

## گام بعدی

با اتصال یک گوشی یا emulator و نصب SDK/JDK، خروجی APK محلی را بسازید و روی همان اپ یک sync واقعی اجرا کنید؛ سپس پایگاه داده را پس از راه‌اندازی مجدد بخوانید. بعد از تأیید ماندگاری، یک corpus محدود از گزارش‌های واقعی و fixtureهای مشترک برای parity موتور FTS اندروید/دسکتاپ بسازید. تا آن زمان قیف snapshot نباید «زنده» معرفی شود.
