## ۹. سند تحویل و قراردادهای API به تیم Coder (Coder Handoff Specification)

تیم Coder در مأموریت بازطراحی واسط کاربری می‌تواند با اتکا به قراردادهای زیر اقدام به طراحی صفحات نماید:

### ۹.۱. قرارداد اندپوینت چارت و اندیکاتورها (`GET /api/chart/{symbol}`)
* **پارامترها:** `symbol: str`, `adjustment: int` (۰: خام، ۳: تعدیل با مجمع).
* **خروجی تضمین‌شده:**
  ```json
  {
    "symbol": "فولاد",
    "candles": [
      { "time": "2026-10-15", "open": 5400, "high": 5480, "low": 5380, "close": 5420, "volume": 125000000, "last": 5430, "src": "published" }
    ],
    "basis_applied": "last",
    "adjustment_applied": 3,
    "staleness_seconds": 0
  }
  ```

### ۹.۲. قرارداد اندپوینت وضعیت FTS (`GET /api/fts/{symbol}`)
* **خروجی تضمین‌شده:**
  ```json
  {
    "symbol": "فولاد",
    "weekly_trend": "bullish",
    "daily_trend": "bullish",
    "weekly_gate": "pass",
    "setups": {
      "jet": { "active": false, "reason": "فاصله از سقف تاریخی" },
      "choch": { "active": true, "price": 5350 },
      "hourglass": { "active": false, "reason": "RSI در ناحیه اشباع فروش نیست" }
    },
    "verdict": "BUY",
    "as_of": "2026-10-15"
  }
  ```

### ۹.۳. توصیه‌های فرانت‌اند به Coder
1. **پرهیز از بازنویسی منطق روند در جاوااسکریپت:** فرانت‌اند باید مقادیر `weekly_trend` و `daily_trend` را مستقیماً از پاسخ سرور نمایش دهد.
2. **انتخاب موتور چارت:** سوئیچ بین `klinecharts` و `ffc` در تنظیمات فرانت‌اند باید صرفاً پراپرتی `chartEngine` را تغییر دهد؛ هر دو موتور دقیقاً همان آرایه `candles` را تغذیه می‌کنند.
3. **نمایش اصالت داده:** در بالای نمودار، وضعیت مبنای قیمت (`Price Basis: last | closing`) و برچسب کهنگی به صورت شفاف درج شود.
