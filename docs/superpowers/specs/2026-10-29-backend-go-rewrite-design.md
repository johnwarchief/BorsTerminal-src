## ۱. هدف

بک‌اندِ پایتون (FastAPI + pandas/numpy، ~۴۲٬۴ هزار خط) با **یک باینریِ Go** جایگزین می‌شود که:

- همان مسیرها و همان JSON را سرو می‌کند (قرارداد یخ‌زده، فقط افزودنی)؛
- همان SQLite را می‌خواند و می‌نویسد، **بدونِ تغییرِ اسکیما**؛
- همان حلقه‌هایِ سینک/واکشی را می‌گرداند؛
- و تا لحظهٔ درِ G5، پایتون به‌عنوانِ مرجعِ پاریتی و مسیرِ بازگشت سرِ جایش می‌ماند.

موفقیت سه چیزِ سنجش‌پذیر است: **صفر اختلافِ پاریتی**، **اهدافِ منابع/شروع** (§۳)، و **قابلیتِ بازگشت** بدونِ دست‌زدن به داده.

## ۲. چرا Go — و آنچه Go حل نمی‌کند

| دلیلِ مالک | با Go برآورده می‌شود؟ | سنجه |
| --- | --- | --- |
| سرعت و مصرفِ منابع | بله | RSS بیکار < ۸۰MB (از ۲۹۷٫۶)، بازِ پورت < ۰٫۵s (از ۷٫۱)، اولین داده < ۲s (از ۹٫۴) |
| پایداری | بله | باینریِ استاتیک، بدونِ runtimeِ numpy/pandas، خطاهایِ تایپ‌دار؛ درِ B-G4 (soak) |
| نگهداری | بله | نقشهٔ ماژولِ واحد، لایهٔ `store`ِ واحد، تستِ طلایی برایِ معناهایِ یخ‌زده |
| یک‌شدنِ زبان | **نه** | پشته TS + Rust (پوسته) + Go = سه زبان؛ Node/TS این یکی را برمی‌آورد. مالک با علمِ این هزینه Go را انتخاب کرد (۲۰۲۶-۱۰-۲۹). |

## ۴. دامنه و غیرِدامنه

**دامنه:** همهٔ مسیرهایِ `/api/*` (نهایتاً ~۱۰۳ هندلر) با همان قرارداد؛ خواندن/نوشتنِ SQLite؛ حلقه‌هایِ سینک و واکشی؛ ابزارِ پاریتی.

**غیرِدامنه در این طرح:**

- اجرایِ سفارش/کارگزار (`api/execution.py`) — در پایتون می‌ماند تا رأیِ بازنشستگی (§۱۶).
- `api/update.py` و `api/adb.py` — تا همان رأی.
- سروِ فایل‌هایِ ایستا و اتصال به پوستهٔ Tauri (مرحلهٔ S8 پلنِ UI).
- تغییرِ اسکیما، مهاجرتِ داده، تغییرِ `journal_mode`.
- تغییرِ رفتارِ UI یا متنِ رابط؛ این طرح فقط دو قراردادِ افزودنی برایِ UI می‌دهد (§۱۱).

**قیدهایِ ثابت:** هیچ کوکی/توکن/رمز خوانده یا ذخیره نمی‌شود؛ هیچ داده‌ای از ماشین بیرون نمی‌رود؛ هیچ DBِ عملیاتی حذف/بازنویسی/ترمیم نمی‌شود؛ هیچ کنترلِ واقعیِ ADB برایِ آزمونِ گیت اجرا نمی‌شود؛ فرآیندِ کشته‌شده فقط PIDی است که همین کار بالا آورده.

## ۵. توپولوژیِ گذار

**فاز A — هم‌زیستی (B0..B5):**

- پایتون می‌ماند و **تنها** گردانندهٔ حلقه‌هایِ سینک/واکشی است (قیدِ §۹ِ فایلِ تصمیمات).
- Go روی پورتِ مستقل (`8198`) و **فقط-خواندنی** روی `market.db`؛ `user.db` خواندنی/نوشتنی با `busy_timeout` — بدونِ تغییرِ `journal_mode`.
- UIِ v2 در dev از پروکسیِ مسیربه‌مسیرِ `vite` استفاده می‌کند: مسیرهایِ پورت‌شده به Go، بقیه به پایتون. هر مرحله یک ردیف از لیست به Go می‌چسبد.
- مسیرهایِ پورتنشده با `501 {"status":"error","code":"NOT_PORTED","route":…}` پاسخ می‌دهند — صادق، و هرگز پیش‌فرضِ محصولِ منتشرشده نیست.

**فاز B — بریدن (G5):**

- Go روی `8001`، حلقه‌ها به Go، پایتون خاموش؛ UI بدونِ یک خط تغییر.
- باینریِ Go تا G5 در بستهٔ نصب نمی‌رود؛ مسیرِ product همان پایتون است.

**قاعدهٔ نوشتن:** فقط یک فرآیند حلقهٔ زندهٔ TSETMC را می‌گرداند. `user.db` نوشتن‌هایِ کوتاه (واچ‌لیست) را از هر دو طرف می‌پذیرد چون SQLite با قفلِ خودش سریالایز می‌کند؛ اگر در عمل قفل‌شدن دیده شد، نوشتنِ واچ‌لیست تا B5 به پایتون برمی‌گردد.

**درزِ `BORS_DATA_DIR`:** در `bors_config.py` اگر این متغیر تنظیم شده باشد، `WORK_DIR` و در نتیجه مسیرِ `market.db`/`user.db` از آن می‌آید. پیش‌فرضِ رفتار دست‌نخورده می‌ماند و با یک تست قفل می‌شود. مصرف: فقط پاریتی و CI.

### ۶.۱ وابستگی‌ها و زنجیرهٔ ساخت

- Go 1.26.3 (نصب‌شده روی این ماشین)، بیلدِ ویندوز amd64، **بدونِ cgo**.
- HTTP: `net/http`ِ استاندارد با الگویِ مسیرِ Go 1.22+؛ بدونِ فریم‌ورک.
- SQLite: `modernc.org/sqlite` (خالصِ Go). اگر در B1 هدفِ p95 محقق نشد، `mattn/go-sqlite3` (نیازمندِ gcc) با همان هارنس سنجیده می‌شود و تغییرش رأیِ فنیِ ثبت‌شده است.
- JSON: `encoding/json`؛ ترتیبِ کلید در تست تثبیت می‌شود (در پاریتی بی‌اثر است). لاگ: `log/slog`. تست: `testing`.

## ۷. قراردادِ HTTP

- **مسیرها و نامِ فیلدها یخ‌زده‌اند.** فقط افزودنِ فیلد مجاز است؛ حذف/تغییرِ نام/تغییرِ معنا تا G5 و بدونِ رأیِ ثبت‌شده ممنوع.
- **پاکت:** پاسخ‌هایِ موفقِ خودِ برنامه `{"status":"success", …}` (یا `"ok"` در mstat) و خطاهایِ سطحِ هندلر `{"status":"error","message":…}`؛ شکلِ هر مسیر عیناً از پایتون گرفته می‌شود، نه از حافظه.
- **خطاهایِ چارچوب:** ۴۰۴ و ۴۲۲ به شکلِ FastAPI (`{"detail": …}`) بازتولید می‌شوند؛ اعتبارسنجیِ پارامترها (نوع/محدوده) با همان کدها.
- **هدرها:** حداقل `content-type` و کدِ وضعیت مقایسه می‌شوند؛ فهرستِ هدرهایِ دیگر (مثلِ `cache-control`) در B0 با یک diffِ هدر تثبیت و در هارنس قفل می‌شود.
- **مسیرِ پورتنشده:** `501` با کدِ `NOT_PORTED`.
- **SPA catch-all:** تا اتصال به پوسته، Go فقط `/api/*` و `/healthz` را سرو می‌کند.

## ۸. مرحله‌ها

هر مرحله: **یک کامیت** + فایلِ `_audit/parity/<stage>.json` در همان کامیت + گزارشِ عددی به مالک.

| مرحله | محتوا | درِ پذیرش |
| --- | --- | --- |
| **B0 پایه** | اسکلتِ `backend-go/`، config و پرچم‌ها، اتصالِ DB (market فقط‌خواندنی / user خواندنی‌نوشتنی)، پاکت/خطا/catch-all، `/healthz`، درزِ `BORS_DATA_DIR` در پایتون + تست، `cmd/parity` | `go build`/`go vet`/`gofmt -l` پاک؛ بازِ پورت < ۰٫۵s؛ RSS بیکار < ۸۰MB؛ نوشتن روی market.db رد می‌شود؛ ۴۰۴/۴۲۲/۵۰۱ مثلِ تعریف؛ صفر SQL بیرونِ `store` |
| **B1 تابلو** | `/api/market`، `/api/market/delta`، `/api/market/sync-state` | همان ردیف‌هایِ پایتون و همان ترتیب؛ payload ≤ پایتون؛ p95 ≤ ۰٫۵× |
| **B2 وضعیت** | ۱۳ مسیرِ GETِ `/api/mstat/*` (summary، histogram، thermometer، depth، clientsplit، market-snapshot، phase، mainwatch، industries، smart-money، timeline، phases، board) | همهٔ اعداد Δ=۰؛ رشته‌هایِ فاز یکسان؛ POST همچنان ۵۰۱ |
| **B3 چارت** | ۹ مسیرِ `api/chart.py` (chart، key-levels، chart-db، ma، order-book، orderbook/watch، …) | هندسهٔ کندل برایِ ۵ نماد (رویدادِ تعدیل، صندوقِ اهرمی، بی‌داده) یکسان؛ MA سه‌حالتی؛ ۵ ردیفِ سفارش |
| **B4 بنیادی و نوار** | ۶ مسیرِ `api/fundamental.py` + `/api/tape-history` + فیلدِ افزودنیِ سریِ ماهانه | پنج محور با حالت‌هایِ بی‌نظر/داده‌گپ یکسان؛ ۷ فیلترِ نوار یکسان؛ سریِ ماهانه دقیقاً همان ردیف‌هایِ پایتون |
| **B5 کاربر** | واچ‌لیست + اعلان‌ها + `?symbol=` | نوشتنِ user.db رویِ کپی ردیف‌به‌ردیف یکسان؛ سقفِ ۵۰؛ افزودن/حذفِ مکرر |
| **B6 حلقه‌ها** | سینک/کدال + POST snapshot | پخشِ ضبط‌شدهٔ HTTP؛ دِلتایِ DB ردیف‌به‌ردیف؛ مسیرِ ۴۲۹؛ بدونِ شبکهٔ واقعی |

**قاعدهٔ ترتیبِ UI:** فیلدِ افزودنیِ UI **اول در پایتون** (مرجعِ پاریتی) اضافه و تست می‌شود، بعد Go آن را با پاریتی پورت می‌کند. این‌طور کارِ UI پشتِ بازنویسی نمی‌ماند و Go چیزی از خودش اختراع نمی‌کند.

## ۹. گیت‌ها

| گیت | چیست | قبولی |
| --- | --- | --- |
| **B-G1** | پاریتیِ خواندن رویِ کپیِ یخ‌زده (پایتون و Go هم‌زمان، حلقه خاموش) | صفر اختلاف پس از حذف‌هایِ اعلام‌شده؛ بیشینهٔ دلتایِ عددی گزارش‌شده |
| **B-G2** | پاریتیِ نوشتنِ user.db رویِ کپی | ردیف‌به‌ردیف یکسان، فقط ستون‌هایِ زمانی مستثنا |
| **B-G3** | پاریتیِ حلقه با پخشِ ضبط‌شده | دِلتایِ DB ردیف‌به‌ردیف؛ صفر درخواستِ واقعی؛ صفر کنترلِ ADB |
| **B-G4** | پایداری | soakِ ۶۰ دقیقه: رشدِ RSS < ۱۰٪، صفر خطایِ مدیریت‌نشده؛ ۱۰ ریاستارت بدونِ قفلِ جامانده |
| **G5** | بریدنِ نهایی — **رأیِ مالک** | همهٔ گیت‌هایِ بالا + تأییدِ مالک |

`go test -race` رویِ ویندوز به زنجیرهٔ C نیاز دارد؛ اگر موجود نبود، به‌جایِ آن تستِ هم‌زمانیِ stress اجرا و همین محدودیت در گزارش ثبت می‌شود — ادعایِ race-free بدونِ ابزار ممنوع.

## ۱۰. هارنسِ پاریتی

- `cmd/parity --py http://127.0.0.1:8299 --go http://127.0.0.1:8298 --cases cases/<module>.json` (پورت‌هایِ جدا از نمونهٔ devِ ۸۱۹۸ تا با آن قاطی نشود)
- **کپیِ یخ‌زده:** `_audit/parity/db-<sha8>/` شاملِ `market.db` و `user.db`؛ هر دو سرور با `BORS_DATA_DIR` به آن اشاره می‌کنند. هش و mtime قبل/بعدِ هر دسته چک می‌شود؛ تغییر ⇒ دسته باطل و تکرار.
- **کیس‌ها:** از امضایِ خودِ مسیرها + تماس‌هایِ واقعیِ v2 + لبه‌ها (نمادِ ناموجود، پارامترِ نامعتبر، صندوق، نمادِ بی‌داده، `since`ِ کهنه).
- **canonicalسازی:** ترتیبِ کلید بی‌اثر؛ رشته بایت‌به‌بایت **دقیق**؛ عدد: اگر هر دو صحیحِ ریاضی باشند برابرِ عددی کافی است (۱ و ۱٫۰ یکی‌اند)، وگرنه تلورانسِ نسبیِ ۱e-۹ **با گزارشِ بیشینهٔ دلتا**؛ آرایه‌ها بی‌مرتب‌سازی (ترتیبِ تابلو/کندل خودش داده است).
- **حذف‌ها:** فقط مسیرهایِ صریحِ JSON (مثلِ `meta.generated_at`، `age_sec`)؛ بدونِ الگویِ عام؛ هر حذف در گزارش چاپ می‌شود.
- **خروجی:** `_audit/parity/<stage>.json` — پاس/ردِ هر کیس، اولین مسیرهایِ اختلاف، بیشینهٔ دلتا، بایت‌ها، p50/p95ِ هر دو، هشِ DB.
- **تستِ طلایی:** `tools/parity/gen_golden.py` وکتورهایِ `price_basis`/`candle_contract`/`codal_periods` را از پایتون می‌سازد و در `backend-go/internal/*/testdata/` کامیت می‌کند؛ `go test` بدونِ پایتون اجرایشان می‌کند.
- هیچ درخواستِ شبکه‌ای و هیچ ADB در هارنس اجرا نمی‌شود؛ پورت‌ها و PIDها مالِ خودِ هارنس‌اند.

## ۱۱. قراردادهایِ دادهٔ UI

**تنها فیلدِ تازه — سریِ ماهانهٔ شاخص ۱** (افزودنی، در پایتون اول):

```
indicators['1'].monetary.series = [
  { "year": 1405, "month": 1, "monthly_mrl": …, "ytd_mrl": …, "ytd_prev_mrl": … }
```

- منبع: همان `fts_engine.monthly_series` که `ind1a_monetary_growth` امروز می‌خواند؛ بدونِ کوئریِ دوم و بدونِ قاعدهٔ دوم؛ حداکثر ۱۲ ردیفِ سالِ مالیِ جاری، صعودی بر حسبِ ماه.
- `monthly_revenue` ستونِ رسمیِ کدال است، نه تفاضلِ ساختگی؛ `ytd_revenue_prev` هم ستونِ «مقایسه با دورهٔ مشابه سال قبل».
- نبودِ مقدار `null` است، هرگز صفر. واحد: جدول ستونِ واحد ندارد، پس `unit: null` و `unit_note`ِ موجود به ارث می‌رسد و نمودار **درصدِ رشد** می‌کشد، نه ریال.
- اگر سری نبود: `[]` (نوعِ پایدار).

**بدونِ فیلدِ تازه (داده امروز هست):** کارت ۳ (`indicators['3']`: `gross_profit_bt`، `revenue_bt`، `period_end`، `basis`، `threshold`، `optimal`)؛ کارت ۴ (`indicators['4']` + `annual{annual_sales_mrl, months_used, scale_factor}` + `market_cap_source/error/asof`)؛ کارت ۲ (`eps_series`)؛ نوارِ بالا (۱۳ مسیرِ mstat که B2 پورت می‌کند).

**نوارِ بالا:** ۴ کارتِ اصلی می‌مانند؛ جزئیات در hover/preview و یک ردیفِ بازشدنی می‌آید (رأیِ ۲۰۲۶-۱۰-۲۹).

**سایدبار:** `?symbol=`ِ افزودنی رویِ `/api/notifications/feed` (شکلِ پاسخ بدونِ تغییر)؛ سه اطلاعیهٔ آخرِ همان نماد پایینِ سایدبار؛ بی‌خبر ⇒ یک خطِ حالتِ خالی.

**فونتِ 2K:** media query در `styles.css`: ≥۱۹۲۰px یک پیکسل و ≥۲۴۰۰px دو پیکسل به کلاس‌هایِ `t-*`؛ ارتفاعِ ردیف‌ها دست نمی‌خورد. تأییدِ بصریِ مالک رویِ ۲۵۶۰ لازم است.

**سازگاری:** اسکیمایِ zod در v2 `looseObject` است، پس فیلدِ افزودنی چیزی را نمی‌شکند؛ یک تستِ اسکیما برایِ فیلدِ تازه اضافه می‌شود.

## ۱۲. خطا، رصد، لاگ

- دو شکلِ خطا (بندِ §۷) عیناً بازتولید می‌شوند؛ `NOT_PORTED` فقط در dev/هم‌زیستی.
- یک خطِ JSON به ازایِ هر درخواست: زمان، متد، مسیر، کد، ms، بایت. مقادیرِ حساس (توکن، کوکی، پارامترِ احراز) لاگ نمی‌شوند.
- فایلِ `logs/borsd.log` با چرخشِ ۵MB×۳؛ خلاصهٔ خطاها در حلقهٔ حافظه (۵۰ موردِ آخر) برایِ `/healthz`.
- `/healthz`: نسخه، مسیر و حالتِ DB، وضعیتِ حلقه‌ها، آخرین سینک، RSS — بدونِ تماسِ شبکه‌ای.
- هیچ telemetry و هیچ ارسالِ بیرونی وجود ندارد.

## ۱۳. آزمون

- **واحد:** تستِ طلاییِ معناهایِ یخ‌زده (بدونِ پایتون، قابلِ اجرا در CI).
- **store:** رویِ یک DBِ آزمونِ کوچکِ ساختگی (اسکیما + چند ردیفِ صریحاً ساختگی، فقط برایِ تست).
- **هندلر:** `httptest` با همان serializer؛ شکلِ خطا و کدِ وضعیت.
- **پاریتی:** B-G1..B-G3.
- **پایداری:** B-G4.
- **فرانت:** تستِ اسکیمایِ فیلدِ تازه + سبزماندنِ کلِ مجموعهٔ v2 در هر مرحله.

اجرایِ اجباریِ هر مرحله: `go test ./...`، `go vet ./...`، `gofmt -l` خالی، و `npx vitest run`ِ v2 سبز.

## ۱۴. کارایی — روشِ سنجش

همان ماشین، همان کپیِ DB، حلقه خاموش؛ ۵ اجرایِ گرم‌کردن و ۲۰ نمونه برایِ هر مسیر؛ گزارشِ p50/p95ِ هر دو طرف و بایت‌ها. RSS پس از ۶۰ ثانیه بیکاری. «بازِ پورت» = از شروعِ فرآیند تا اولین ۲۰۰ روی `/healthz`. «اولین داده» = اولین ۲۰۰ روی `/api/market`.

| هدف | مقدار |
| --- | --- |
| RSS بیکار | < ۸۰MB |
| بازِ پورت | < ۰٫۵s |
| اولین داده | < ۲s |
| p95ِ هر مسیر | ≤ ۱٫۰× پایتون |
| p95ِ سه مسیرِ سنگین (market، chart، fundamental) | ≤ ۰٫۵× |

## ۱۵. ریسک‌ها و بازگشت

| ریسک | اثر | کاهش |
| --- | --- | --- |
| پاریتی باگ‌به‌باگ، باگِ پایتون را منتقل کند | باگِ قدیمی در Go هم بماند | قاعدهٔ «رفعِ رفتار = تصمیمِ جدا + تست در هر دو»؛ هیچ اصلاحِ قاچاقی |
| موتورهایِ بزرگ (mstat، chart، fts) دقیق پورت نشوند | اختلافِ عددیِ خاموش | تستِ طلایی + پاریتیِ کامل + گزارشِ بیشینهٔ دلتا |
| پارسرِ کدال با WAF/۴۲۹ | ناپایداریِ واکشی | فقط پخشِ ضبط‌شده در گیت؛ بدونِ شبکهٔ واقعی؛ ADB خارج از دامنه |
| دو نویسنده رویِ user.db | قفل/تصادم | نوشتنِ کوتاه + `busy_timeout`؛ در صورتِ دردسر، واچ‌لیست تا B5 به پایتون |
| Go زبانِ سوم | هزینهٔ نگهداری | پذیرفته‌شده توسطِ مالک؛ نقشهٔ ماژول و تستِ طلایی برایِ کاهشِ هزینه |
| بسته‌بندی/نصبِ باینریِ تازه | ریسکِ ریلیز | خارج از این طرح تا G5؛ مسیرِ نصب همان پایتون |

**بازگشت:** در فاز A با برگرداندنِ یک ردیف در پروکسی؛ در G5 با روشن‌ماندنِ پایتون در بسته برایِ یک ریلیز و یک پرچم. چون اسکیما و داده تغییر نمی‌کند، بازگشت به دادهٔ بازنویسی‌شده نیاز ندارد.

## ۱۶. رأی‌هایِ باز (مالک)

1. زمانِ G5 (بریدنِ نهایی).
2. فهرستِ بازنشستگیِ مسیرهایِ فقط-نسخهٔ-۱ (execution، update، adb، …) — شرطِ B7.
3. تأییدِ بصریِ پنج کارِ UI رویِ اسکرین‌شات (کارت‌ها، نوارِ بالا، سایدبار، فونتِ ۲K).
4. اتصالِ باینری به پوستهٔ Tauri (مرحلهٔ S8 پلنِ UI) — این طرح فقط تا درِ API می‌رود.

## ۱۷. خارج از این طرح

اتصال به پوسته، نصاب، مانیفست/پچِ دلتا، ریلیز، و هر تغییرِ UI فراتر از سه قراردادِ §۱۱. آن‌ها در پلنِ UI (`S8..S10`) و ریلیز می‌مانند.
