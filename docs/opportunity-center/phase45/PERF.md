# کارایی — پیش و پس از پورتِ کانونیک — فاز ۴٫۵

مأموریت §۹: اندازه‌گیری فقط پس از درستی؛ مبنایِ پیش از تغییر؛ و هیچ بهینه‌سازی‌ای
نباید خروجی/پوشش را عوض کند. این دور **هیچ بهینه‌سازی اعمال نشد**؛ فقط B0 (کدِ پیش
از پورت) و B1 (کدِ کانونیکِ فعلی) رویِ همان کورپس و همان ماشین اندازه‌گیری شدند.

## روش

| قلم | مقدار |
| --- | --- |
| ابزار | `TestP45Bench` (`backend-go/internal/chart/phase45_bench_test.go`) با تگِ `phase45` |
| کورپس | همان ۳۰ نماد، همان کپیِ آزمایشگاهیِ `_audit/phase45/lab` |
| بستهٔ تقویم | `ra365-r32d` برایِ هر دو سو (`BORS_WM_CALENDAR_DIR`) |
| B0 | worktree موقت روی `64c691ce` (کدِ چارت پیش از پورت) |
| B1 | همین درخت، پس از پورتِ کانونیک و اصلاحِ S8 |
| گذرها | ۱ گرم‌کردن + ۳ گذرِ اندازه‌گیری؛ عددِ گزارش، گذرِ سردِ بعد از گرم‌کردن |
| Python | همان ۳۰ نماد، `get_chart_db`، ۱ گرم‌کردن + ۳ گذر |

## نتیجه

| سنجه | B0 (پیش) | B1 (پس) | Python (مرجع) |
| --- | --- | --- | --- |
| زمانِ هر نماد | 5.62 ms | 6.72 ms | 708–745 ms (میانه 720) |
| کلِ ۳۰ نماد | 506 ms | 605 ms | 21.3–22.4 s |
| میانگینِ payload | 138,838 B | 162,241 B | 187,842 B |
| بیشینهٔ payload | 169,427 B | 191,776 B | 221,315 B |
| heap delta (یک‌shot) | 0.99 MB | 10.9 MB | — |
| نسبت به Python | ~128× سریع‌تر | **~107× سریع‌تر** | 1× |

خواندن: B1 نسبت به B0 حدود **+19.5٪ زمان** و **+16.9٪ payload** دارد. علت، کارِ
**درستی** است که B0 نداشت: mergeِ رویدادِ رسمی، تیزکردنِ دفتری، گام‌هایِ سهام،
بستهٔ تصحیح، coverage و فیلدهایِ شفافیت (`adjustRejected`، `adjustCapability`).
این رگرسیون، هزینهٔ پاریتی است، نه افتِ تصادفی. heap delta تک‌شات و وابسته به GC
است (در اجرایِ قبلیِ B0 عددِ 3.67 MB دیده شد)؛ برایِ داوریِ حافظه کافی نیست.

## چه اندازه‌گیری نشد

| قلم | وضعیت |
| --- | --- |
| CPU/RSS پایدار در اجرایِ طولانی | NOT_MEASURED (فقط heap تک‌شات) |
| نرخِ hit کش (MA/patterns ۶۰ ثانیه؛ چارت بی‌کش) | NOT_MEASURED |
| هزینهٔ به‌تفکیک: query / adjustment / aggregation / FTS | NOT_MEASURED (کلِ مسیر یک عدد است) |
| API transfer رویِ شبکهٔ واقعی | فقط اندازهٔ payload اندازه‌گیری شد |

## حکم

| محور | وضعیت |
| --- | --- |
| مبنایِ پیش از تغییر ثبت شد | PASS |
