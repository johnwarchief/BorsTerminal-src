## 3. Zero-Python runtime proof plan

1. **Bundle** - `cmd/bundlecheck` (A7) scans the shipped tree for Python extensions,
   `_internal`, `site-packages` and PyInstaller markers, and requires the Go bundle
   components (`BorsTerminal_Ultimate.exe`, `BorsTerminal_Shell.exe`,
   `frontend/index.html`, `Version.txt`).
2. **Process tree** - `cmd/runtimecheck` (A6) starts `borsd` with a temp
   `BORS_DATA_DIR`, reads `/api/health`, enumerates the process tree and proves no
   `python`/`py`/`pythonw`/`libpython` is present; it kills only its own PID and
   writes a JSON artifact.
3. **Installer** - `delivery-contract` installs the built setup into a runner temp
   directory (never the real install/registry), scans the installed tree for Python
   artefacts, runs `runtimecheck` against the installed EXE, then uninstalls (A8).
4. **Wiring and evidence** - A5 adds the `zero-python-runtime` job and the installer
   proof; A9 records the final workflow results. Python stays CI data/build tooling
   only; it is never part of the product runtime.

## 5. Method (and what was deliberately *not* migrated)

- Every suite was read for its module under test and its imports (`ast`), then mapped
  to the Go/TS package that owns that surface now. Classification does not require
  executing the suite: 177 suites cannot execute on this machine for a missing
  third-party package, and a suite is never called passing unless it ran.
- `MIGRATE` is used only when a named Go test asserts the same contract (the guard
  requires `func TestName(` / a quoted `it("...")` title in a repo file).
- `DEPRECATE` names the owning package and the missing coverage when the Go test set
  covers only part of the Python guard. Examples of partial coverage that stayed
  `DEPRECATE` instead of a false `MIGRATE`: the mstat session-aware TTL
  (`mstat_cache_durability_v1.py` - Go has one 45s TTL), the unitless-never-1e6 rule
  (`codal_unit_scale_v1090.py`), the board cache invalidation/empty-window controls
  (`board_hist_cache_v1056.py`), the closing-anchor invariance
  (`price_basis_v1070.py`), `get()` on a missing watchlist row
  (`user_watchlist_v1.py` - Go asserts upsert identity and the cap, not that claim),
  the notebook derivation of the tape formulas (`tape_filters_v1034.py`), the FTS
  analysis-cache basis and the chart-read basis re-resolution (`fts_cache_basis_v1078.py`
  - `internal/chart` appends the basis to the key at `analysis.go:98`, no Go test
  asserts it), the `StaleMax` cap and its negative control (`mstat_swr_v1111.py` - the
  Go tests advance only `DefaultTTL+1s`), cross-DB cache-key isolation
  (`mstat_snapshot_cache_v1.py` - `TestCallKeysAreIsolated` isolates panel/parameter
  keys inside one `Service`), and the `as_of` key's ruleset/tf components
  (`test_fts_asof_cutoff.py`).
- `B` now also covers stdlib-only CI-tooling guards that must keep running (the suite
  registry, runner profiles, version anchors, Persian glyphs, repo hygiene), which is
  the controller's ruling for the two new CI-tooling tests.
- Suites with no Go counterpart (execution/bot/broker/sarkhati, the Python updater,
  the PyWebView boot page) are `DEPRECATE` with `no replacement: ...` and a named
  reason, never a fabricated equivalence.
