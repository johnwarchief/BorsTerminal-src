# مشخصاتِ اجراییِ صفحهٔ بازار (S1) — اپِ تازه

**مرجعِ بصری (تأییدشده):** پیش‌نمایشِ `http://127.0.0.1:5303/market_live/` (کپیِ پروتوتایپِ v2 با دادهٔ زنده)؛ قراردادِ بصری: [DESIGN.md](../DESIGN.md)؛ تصمیم‌ها: §۱۳ فایلِ تصمیمات.
**دامنه:** فقط صفحهٔ بازار در `frontend-v2/`. بقیهٔ صفحات/پنل‌ها در گفت‌وگوهای بعدی.
**قاعده:** انتقال یک‌طرفه از اپِ قدیم به اپِ تازه؛ UIِ قدیم تا هم‌ارزی fallback می‌ماند.

## ساختار (همان پروتوتایپ)

1. **Rail**: برند + ۱۱ مسیر + وضعیتِ تازگی + چهار تم + جمع‌شدن (208px / 52px).
2. **Topbar** (44px): نقطهٔ وضعیتِ بازار + تاریخ، جستجو/پالت، تب‌ها.
3. **Status strip** با سه حالتِ ماندگار: کامل (≈134px در 1366، ≈158px در ≥2200) / نوار (33px) / کمینه.
4. **Board toolbar**: جستجو، پروفایلِ ستون‌ها (عمومی/معاملات/بنیادی/تکنیکال)، چگالی، پاپ‌اورِ ستون‌ها، نماهایِ ذخیره‌شده و خروجیِ CSV از ردیف‌های دیده‌شده.
5. **Tape bar** (22px چیپ): ۷ فیلتر + «همه»، **چندانتخابی با کلیدِ صریحِ AND/OR**، شمارش روی پایهٔ دیده‌شده (بعد از فیلترِ نوعِ دارایی).
6. **Board**: CSS grid، سرِ چسبانِ ۲۷px، ردیف 30/36/44 و در ≥2200px 34/40/48، سلولِ نماد دوخطی (کد + نشان‌ها + نام)، نشان‌های تابلوخوانی.
7. **Quick drawer** روی تابلو با کلیکِ ردیف؛ بستن با Esc/backdrop.
8. **تم‌ها**: برنجیِ تیره (پیش‌فرض)، روشنِ گرم، ترمینال، روشنِ سرد؛ `prefers-reduced-motion` رعایت می‌شود.

## رفتارها

- مرتب‌سازیِ پیش‌فرض: ارزشِ معاملات نزولی؛ کلیکِ سرِ ستون جهت را عوض می‌کند؛ اعدادِ فارسی با `fa.ts`.
- جستجو روی کد و نام با یکسان‌سازیِ ي/ك و نیم‌فاصله.
- پروفایل، چگالی، حالتِ وضعیت و تم در `localStorage` می‌مانند.
- کلیکِ ردیف → کشویِ سریع؛ کلیکِ دوباره/بستن → برگشت و بازگشتِ فوکوس به کنترلِ آغازگر. انتخاب، سابقه و اشتراکِ عمق با `ins_code` است، نه نمادِ نمایشی.
- دیده‌بان‌ها روی **کل تابلو** کار می‌کنند (مستقل از فیلترهای تابلوخوانی)، حداکثر ۱۵ ردیف نشان می‌دهند و شمارشِ کامل را «۱۵ از N» می‌نویسند.
- عمقِ بازار اگر نشستش با روزِ تابلو یکی نباشد «کهنه» برچسب می‌خورد، سطرهایش زنده شمرده نمی‌شوند و جمع‌های نشستِ جاری با آن نمایش داده نمی‌شوند.
- نمایِ نام‌دار، فیلترها، چیپ‌ها و AND/OR، ستون‌ها، جستجو، مرتب‌سازی، چگالی و نرخِ پایش را نگه می‌دارد؛ بازیابی/حذف و بازگشتِ فوکوس قراردادِ آن است.
- خروجیِ CSV فقط ردیف‌های فیلترشده و مرتب‌شدهٔ روی تابلو را با BOM، `sep=;` و سطرهایِ ردپا می‌دهد؛ سلولِ متنیِ آغازشده با = + - @ در صفحه‌گسترده بی‌اثر می‌شود.
- صفحه‌کلید: Ctrl/Cmd+K جستجو را فوکوس می‌کند (با کشویِ باز، اول کشو بسته می‌شود)؛ یک ردیف در هر لحظه tabbable است و Arrow/Home/End فوکوس را می‌گردانند؛ Enter/Space کشو را باز می‌کند.
- هیچ عددِ ساختگی: ستونِ بی‌منبع در پروفایلِ پیش‌فرض نیست و در پاپ‌اور «وصل نیست» می‌خورد.

## نقشهٔ داده

| ستون/بخش | منبع | وضعیت |
|---|---|---|
| نماد/نام/صنعت | `symbol`/`name`/`sector_name` | ✓ |
| آخرین / پایانی / تغییر٪ | `p_last` / `p_closing` / `percent_change` یا مشتق از دیروز | ✓ |
| حجم / ارزش / معاملات | `q_tot_tran` / `q_tot_cap` / `z_tot_tran` | ✓ |
| P/E / ارزشِ بازار | `pe` / `mcap` | ✓ |
| ۷ فیلتر و نشان‌های تابلوخوانی | `f_smart…f_jet` | ✓ |
| نوعِ دارایی (پایهٔ تابلو) | طبقه‌بندیِ رسمیِ محصول (۵ نوعِ پیش‌فرض) | ✓ (پورت) |
| شاخصِ کل / هم‌وزن | `/api/index/tedpix` | ✗ فعلاً (در دروازهٔ آفلاین 502) |
| ارزشِ خرد / تفکیکِ حقیقی–حقوقی | اندپوینتِ وضعیت (نگاشتِ بعدی) | ✗ |
| EPS | در `/api/market` نیست | ✗ |
| اسکن/هم‌راستاییِ تکنیکال | اندپوینتِ FTS/اسکن | ✗ |
| وضعیتِ باز/بسته | منبعِ رسمیِ وضعیت (کشفِ اندپوینت) | ✗ — تا آن موقع فقط «آخرین همگام‌سازی» |

قاعدهٔ نمایشِ ✗: در پروفایلِ پیش‌فرض نمی‌آید؛ در پاپ‌اورِ ستون‌ها با برچسبِ «وصل نیست»؛ هیچ جایگزینِ صفر/تخمینی ندارد.

## خارج از دامنه (گفت‌وگوی بعدی)

آستانه‌های فیلترِ سریع، کلیدِ پسوندِ عددی، فیلترِ زنده/کهنه، پیکربندیِ بیش از پروفایل، دروازهٔ ورود، و بقیهٔ ۱۰ مسیر.

## پذیرش

- اسکرین‌شات 1366/1920/2560 و اندازه‌گیریِ چگالی (30/36/44 و 34/40/48).
- شمارشِ ۷ فیلتر = پیلودِ همان لحظه روی پایهٔ دیده‌شده؛ شمارشِ پایه در «همه».
- بارگذاریِ اولیه < ۱s روی دادهٔ محلی؛ بدونِ خطای کنسول.
- `tsc` صفر خطا؛ تست‌های واحد برای اسکیما/فیلتر/مرتب‌سازی/شمارش/نماها/خروجی؛ تستِ DOM و صفحه‌کلید/فوکوس سبز.
- رأیِ بصریِ مالک (خوداعلام نشود).
