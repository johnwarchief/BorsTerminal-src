# راهنمای منابع FTS

## تقدم و اعتبار

1. **منبع روش‌شناسی:** docs/جزوه FTS.pdf و docs/FTS.CHART_3.pdf.
2. **تصحیح‌های صریح مالک:** OWNER_RULINGS.md، وقتی مورد اختلاف و رأی صریح را مشخص کرده باشد.
3. **مشخصات و گزارش‌های مهندسی:** docs/FTS_SPEC.md، docs/FTS_SYSTEM_SPECIFICATION_v2.md، FTS_LOGIC_AUDIT_AMENDMENT.md و سایر auditها. این‌ها اسناد مشتق‌شده یا زمان‌دارند و نباید بی‌بررسی بر PDF یا رأی صریح مالک تقدم داده شوند.
4. **رونوشت‌ها و متن استخراج‌شده:** FTS_CHART3_extracted_text.txt، فایل‌های transcription_*.md و jozve_FTS_handwritten_pages_*.md. برای جست‌وجو مفیدند؛ در ابهام، صفحهٔ PDF را ببینید.

## هشدار دربارهٔ رونوشت‌های هم‌پوشان

رونوشت‌ها بازه‌های هم‌پوشان دارند، از جمله transcription_p19-p22.md و transcription_p19-p27.md، همچنین transcription_p23-p27.md، transcription_p28-p31.md و transcription_p28-p34.md. این نام‌ها به معنی جدیدتر یا معتبرتر بودن یکی نیستند؛ هیچ‌یک را به‌تنهایی متن نهایی فرض نکنید.

## چه چیزی گزارش اجرای امروز نیست؟

گزارش‌های classifier، funnel، parity، performance و ممیزی کد تصویر یک تاریخ و یک نسخه از مخزن‌اند. قبل از استفاده برای تغییر کد، branch و کد جاری را دوباره بررسی کنید. در تناقض بین خروجی الگوریتم و مرجع انسانی، خروجی الگوریتم نباید مرجع حقیقت خودش تلقی شود.
