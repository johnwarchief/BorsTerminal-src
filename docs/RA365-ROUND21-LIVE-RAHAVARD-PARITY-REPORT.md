## ۵. نتایج Raw به تفکیک فیلد

تعریف‌ها (پیش از دیدن نتیجه ثابت شدند):

- **exact:** قیمت `|d| ≤ 1e-9`، حجم `|d| ≤ 1e-9`.
- **tolerance:** قیمت `|d| ≤ max(0.5, 1e-6×|ref|)`، حجم `|d| ≤ 1`.
- **rounding:** قیمت `|d| ≤ max(1, 5e-4×|ref|)`، حجم `|d| ≤ 1e-6×|ref|`.
- **displayed:** کندل همان‌طور که چارت نشان می‌دهد (مبنای `last`، با `widen` قرارداد). **literal:** `high_raw/low_raw` پیش از widen.
