   حالا یک سرورِ stdlib روی پورتِ آزاد، صفحۀ فارسیِ پیشرفت را سرو می‌کند و
   خودش آدرس را به اپِ واقعی می‌سپارد. `bors_config` جریان‌خوان شد (رمِ هم‌زمان
   ~۱۵۵MB → بلاکِ ۴MB) و phases: `check / data-meta / download / extract /

   `market.db.lzma` واقعی سنجیده شد (یک اثرانگشت). گارد:

   `_audit/ws13_boot_page.mts` → ۱۵ مقدارِ درصدِ مختلف تا ۱۰۰٪، صفر خطایِ
   کنسول، تحویلِ آدرس و رندرِ پوسته.
