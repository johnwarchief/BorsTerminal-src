## بازیابی روی ماشین دیگر

نیازها: Git، GitHub CLI با دسترسی به مخزن خصوصی، Python نسخهٔ 3.10 یا جدیدتر؛
حداقل ۲ گیگابایت فضای آزاد برای خود کیت، جدا از clone کد و وابستگی‌ها.
از پوشهٔ والد، در Git Bash اجرا کنید:

```bash
gh repo clone johnwarchief/BorsTerminal-src BorsTerminal-resume -- --branch mission/phase49-5-parity-browser-go-main --single-branch
gh repo clone johnwarchief/BorsTerminal-continuation-data continuation-data
python BorsTerminal-resume/_audit/phase49-5/continuation/restore.py --data-root continuation-data --destination BorsTerminal-resume --report restore-result.json
```

برای بازیابی دقیق همین snapshot، پس از clone مخزن داده، کامیت ثبت‌شده در
`REMOTE-RESTORE.json` را checkout کنید؛ سپس دستور Python را اجرا کنید.
اسکریپت ابتدا تمام قطعه‌ها، ZIP و محتوا را بررسی می‌کند؛ سپس فایل‌ها را در
مسیرهای اصلیِ clone تازه می‌نویسد و از اتصال تازهٔ SQLite صحت و شمار ردیف‌ها را
می‌سنجد. فایل موجود، WAL، SHM یا journal موجود موجب توقف می‌شود؛ حتی فایل
بایت‌یکسان هم بازنویسی نمی‌شود. در صورت قطع‌شدن هنگام کپی نهایی، عملیات تراکنش
کل پوشه نیست: برای تکرار از مقصد تازه استفاده کنید، نه حذف دیتابیس کاری.

## ادامهٔ مأموریت

- شاخهٔ دائمی Go، `go-main` است. مأموریت فعلی از آن منشعب شده؛ مأموریت بعدی Go
  نیز از همین شاخه منشعب شود، نه main قدیمی.
- DB مستقل ۴۳ نماد، سنجش Runtime برای ۱۳ نماد و شواهد مرورگر برای ۳۰ نماد هنوز
  ساخته نشده‌اند. هر خروجی تازه باید در checkpoint بعدی همین روند بازیابی را بگذراند.
- V1 فقط مستند بماند. قراردادهای منجمد، Seed/Pilot و دیتابیس نصب‌شده تغییر نکنند.
- توسعهٔ پوشش ۶۷۵ نماد، merge به main برنامه، Tag و Release در دامنه نیست.

## چیزهایی که منتقل نمی‌شوند

رمز، توکن، cookie، profile مرورگر، پوشهٔ `oc` و تنظیمات شخصی عمداً حذف شده‌اند؛
در اجرای سرور توکن تازه تولید می‌شود. Seed/Pilot روی این میزبان وجود ندارند و
ingest مستقل گروه به آن‌ها نیاز ندارد؛ این کیت پشتیبان دیتابیس شخصی برنامه نیست.
Go، Node، Python، Chromium و `node_modules` آرشیو نشده‌اند: وابستگی‌ها را از
manifest/lockfile پروژه نصب کنید. برای مشاهدهٔ زندهٔ حساب Rahavard ورود خود مالک
لازم است؛ هیچ اطلاعات ورود منتقل نمی‌شود. نصب تازهٔ این ابزارها روی ماشین دوم
هنوز آزمایش نشده است.
